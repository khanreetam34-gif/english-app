# v30 test plan

After building in Android Studio:

1. Launch the app.
2. Open Settings, change a setting, save, restart, and verify persistence.
3. Open HUD, toggle visibility, restart, and verify persistence.
4. Open OCR, choose an English-text image, process it, and verify the result.
5. Open Scripts, choose a file, and verify the selected URI dialog.
6. Open Logs, refresh/export/clear.
7. Open About → Diagnostics.
8. Open Feature Status.
9. Open Main → App Health Check.
10. Install the same APK in the supported cloud Android phone and repeat the smoke test.

No proprietary script/native execution is part of this test plan.
