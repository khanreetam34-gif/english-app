# v33 release checklist

Before calling the rebuild release-ready:
- [ ] Android Studio Gradle sync succeeds.
- [ ] Debug APK builds successfully.
- [ ] App launches on the target cloud Android environment.
- [ ] Settings/HUD persist after restart.
- [ ] OCR image selection and English recognition work.
- [ ] Logs refresh/export/clear work.
- [ ] Script file selection/inspection works.
- [ ] Diagnostics and App Health Check work.
- [ ] Feature Status matches the central registry.

This rebuild does not include the original proprietary/native runtime or private backend.
