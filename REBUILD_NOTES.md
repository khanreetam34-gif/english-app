# English Rebuild

This is the first buildable Android project shell reconstructed from the supplied APK.

## Confirmed APK contents
- Android resources and layouts
- `classes.dex`
- `assets/script.lr`
- LuaSocket bundles
- Tesseract English trained data
- OpenCV native library (`armeabi-v7a`)
- JavaMail configuration/resources

## Important
An APK does not contain the original Android Studio source project. Compiled/encrypted components must be reimplemented rather than treated as recoverable source.

This starter deliberately does not reproduce private credentials, private servers, or unauthorized account/game automation. Those parts require an authorized backend/API and an explicit implementation.
