# v32 smoke test

1. Launch app and verify English UI.
2. Change Settings, save, pause/reopen, verify persistence.
3. Toggle HUD and verify persistence.
4. Select an English-text image in OCR and process it.
5. Copy OCR result.
6. Open Scripts and inspect/select a script file.
7. Open Logs; refresh, export, then clear.
8. Run Diagnostics and App Health Check.
9. Open Feature Status and verify the readiness list.
10. Install the same debug APK in the supported cloud Android environment and repeat the checks.

The test intentionally does not execute proprietary/native script code.
