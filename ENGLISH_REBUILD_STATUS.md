# English Rebuild Status

This project is the Android English rebuild target.

Included:
- Native multi-screen UI
- English-only labels
- Main / Settings / Logs / Update / HUD / Scripts / OCR / Web / About
- File pickers for script and image input
- Overlay-permission entry
- Runtime log view
- Cloud endpoint fields

The application is designed as a normal Android APK, so it can be installed in a cloud Android phone that supports APK installation.

It is not a claim that the original compiled native/Lua implementation has been recovered. Those parts require authorized source/runtime implementation.
